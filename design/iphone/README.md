# Wejdan Life OS — iPhone design package

هذه الحزمة هي مرجع تنفيذ تصميم نسخة iPhone الأولى.

## مصادر الحقيقة

- **Figma:** الهوية البصرية، المكونات، الحالات، والنموذج التفاعلي.
- **FigJam:** خريطة الموقع، الرحلات، وقرارات التنقل.
- **SwiftUI/Xcode:** السلوك النهائي، الوصول، الأداء، والتكامل مع iOS.
- **Flutter الحالي:** مرجع مؤقت للمحتوى والمنطق الموجود فقط، وليس مصدرًا لواجهة iPhone الجديدة.

## قواعد العمل

1. نبدأ بأصغر شاشة مدعومة: عرض iPhone بعرض 375 نقطة.
2. كل شاشة لها حالات نجاح وفراغ وتحميل وخطأ واتصال محدود وصلاحيات.
3. العربية RTL والإنجليزية LTR جزء من التصميم منذ أول نسخة.
4. لا نطلب إشعارًا أو صلاحية قبل شرح فائدتها.
5. لا نستخدم اللون أو السلسلة أو الإشعار لإشعار المستخدم بالذنب.
6. أي مكوّن في Figma يحمل اسمًا مطابقًا لمكوّن SwiftUI.

## ترتيب التنفيذ

ابدأ بـ `SCREEN_BACKLOG.md` حسب الأولوية، ثم وثّق المكوّنات في Figma، وبعد اعتماد النموذج انقل كل شاشة إلى SwiftUI مع مرجعها في المصفوفات.
