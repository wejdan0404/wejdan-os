# User flows

النمط المشترك: **الدخول → فهم الحالة → قرار واحد → تنفيذ سريع → تغذية راجعة → تعديل أو إكمال**.

## التهيئة

`اللغة → المجالات → الطاقة والوقت → عادة أو هدف أول → متعة → شرح الإشعارات → خطة اليوم`

تُعرض قيمة أولى قابلة للتنفيذ خلال دقيقة، ويمكن تخطي كل اختيار غير ضروري.

## إكمال عادة

`خطة اليوم → بطاقة العادة → أدنى/عادي/إضافي → إكمال → تأكيد وتراجع قصير → تعديل أو متابعة`

النسخة الأدنى هي الخيار الافتراضي في اليوم منخفض الطاقة.

## يوم منخفض الطاقة

`اليوم → اختيار الطاقة → تقليل الحمل → الضروري فقط + متعة مجانية → إكمال بسيط`

لا تظهر لغة فشل أو عقوبة.

## العودة بعد الانقطاع

`فتح التطبيق → رسالة ترحيب بالعودة → سبب الصعوبة → تعديل واحد → عادة أصغر/وقت جديد → مكافأة العودة`

## إنشاء هدف

`مهني → هدف جديد → النتيجة → المشروع → الخطوة التالية → العادة الداعمة → موعد المراجعة`

## المراجعة الأسبوعية

`أنا → المراجعة → ما نجح → العبء المرتفع → تعديل واحد → تركيز الأسبوع القادم → حفظ`

## تخصيص المظهر

`أنا → تخصيص المظهر → نظام/فاتح/داكن → لوحة أو لون مخصص → شكل البطاقات → الكثافة → معاينة → حفظ/استعادة الافتراضي`

## الإشعارات

`لحظة مناسبة → شرح الفائدة → طلب الصلاحية → أوقات الهدوء → الحد اليومي → تأجيل/تخطي → إيقاف تلقائي عند التجاهل المتكرر`

كل رحلة يجب أن توثق حالة الفراغ والتحميل والخطأ والاتصال المحدود والصلاحية في `STATE_MATRIX.md`.
