# Accessibility matrix

| محور | معيار القبول |
|---|---|
| RTL/LTR | ترتيب المحتوى والدوال يتغير دلاليًا، مع إبقاء الأرقام والتواريخ المقصودة LTR |
| Dynamic Type | لا قص أو تراكب حتى أكبر حجم مدعوم؛ النص يعيد التدفق |
| VoiceOver | اسم وهدف وقيمة وحالة لكل عنصر تفاعلي؛ لا يعتمد المعنى على اللون |
| Contrast | نص وحالات قابلة للقراءة في Light وDark وIncrease Contrast |
| Targets | 44×44pt على الأقل مع مسافة كافية |
| Reduce Motion | إلغاء الحركة غير الضرورية؛ بقاء التغذية الراجعة النصية |
| Keyboard | لا يخفي الحقل؛ زر تم واضح؛ دعم الرجوع من sheet |
| Devices | iPhone SE، قياسي، Pro Max؛ safe areas وDynamic Island |
| Permissions | شرح قبل الطلب، مسار لاحق إلى Settings، عمل أساسي دون الإذن |
| Offline | لا تبدو الشاشة عالقة؛ توضح ما حُفظ محليًا وما ينتظر اتصالًا |
