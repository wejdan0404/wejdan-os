# iPhone release acceptance

- [ ] كل رحلات P0 تعمل من البداية للنهاية.
- [ ] البيانات تبقى بعد الإغلاق وإعادة الفتح.
- [ ] التصدير والحذف يعملان مع تأكيد واضح.
- [ ] الإشعارات اختيارية، قابلة للتأجيل، وساعات الهدوء تعمل.
- [ ] العربية RTL والإنجليزية LTR في Light وDark.
- [ ] Dynamic Type وVoiceOver وReduce Motion مجربة.
- [ ] Face ID للوحدات الحساسة اختياري، والرفض لا يكسر التطبيق.
- [ ] حالات الفراغ والتحميل والخطأ والاتصال المحدود موثقة ومجربة.
- [ ] لا أعطال أو عناصر توحي بميزة غير منفذة.
- [ ] فحص iPhone SE وقياسي وPro Max على جهاز/محاكي.
- [ ] اختبار استخدام صغير وملاحظات TestFlight مغلقة قبل App Store.
